## 一、创办初衷：驱散营销迷雾，回归网络工程本质

在当前的中文互联网讨论中，面向跨境网络选型的资讯环境极度碎片化与同质化。大量所谓的评测博客通篇充斥着夸张的营销话术与未经核验的虚假跑分，将极其复杂的计算机网络工程问题，粗暴简化为单一的买断年付链接。许多初学者在缺乏基础网络认知的前提下盲目付费，随后陷入频繁断流、端口占用、账号封禁甚至服务商失联的困境。

梯子参考（tizicankao.cc）的创立，正是为了终结这种劣币驱逐良币的混乱现状。我们坚信，网络访问工具是一门严谨的现代通信工程科学。用户的实际体验，由本地操作系统架构、局域网安全策略、运营商接入路由、物理光缆时延以及海外数据中心出口品质共同决定。建立科学的技术认知框架，远比盲目追逐一个虚无缥缈的神话更为重要。

## 二、我们的团队与实验室背景

梯子参考的核心团队由多位拥有多年跨国骨干网运维、Linux 系统底层内核调优、网络安全审计经验的资深工程师与开源技术爱好者组成。

我们在本地搭建了覆盖多架构平台的物理测试矩阵，包括：
- **桌面硬件测试平台**：涵盖 Windows 10/11（x86_64 与 ARM64 高通平台）、macOS（Intel 与 Apple Silicon M 系列芯片）、Linux（Ubuntu LTS、Arch Linux 及 Debian 纯终端服务器环境）；
- **移动设备测试环境**：涵盖主流定制 Android 系统（澎湃 OS、ColorOS、OriginOS）的后台保活与电量损耗测试，以及 iOS/iPadOS 封闭沙盒环境下的网络漫游状态机；
- **网络网关与软路由环境**：专门部署基于 OpenWrt、ImmortalWrt、PassWall2 与 HomeProxy 的透明网关测试台架，对 MTU 分片、MSS Clamping 与 TCP BBR 拥塞控制进行物理级抓包分析。

我们所有的评测数据、客户端配置文件与排障流程，均基于实验室物理设备的实测验证，坚决拒绝凭空编造参数与未经测试的搬运抄袭。

## 三、我们的三大不妥协原则

为了保持本技术知识库的长期公信力与纯粹性，梯子参考始终恪守以下三项最高准则：

1. **客观中立先行于商业利益**：
   我们绝不为任何特定商业服务商背书，绝不接受任何形式的排他性赞助。任何服务商的劣势（如晚高峰丢包、高倍率扣费陷阱、客服响应迟缓、合规风控隐患）均在报告中予以客观披露，绝不因商业合作而隐瞒真相。
2. **坚持开源软件官方溯源**：
   本站所收录和推荐的第三方客户端（如 Clash Verge Rev、v2rayN、v2rayNG、FlClash、sing-box 官方核心等），其下载入口 100% 严格指向开发者在 GitHub 等公开代码托管平台的官方 Release 发行渠道，绝不进行二次打包，绝不夹带任何私货木马或捆绑广告软件。
3. **彻底理清分工与责任边界**：
   梯子参考坚守技术中立与学术教育定位。我们专注于探讨网络传输原理、客户端配置教程与设备环境排障；具体的商业套餐选购、实时跨服务商晚高峰测速对比，统一移交至唯一合作选购主站进行独立呈现，保持本站技术内容的纯粹性。

## 四、与选购主站（机场榜一）的协同定位

梯子参考（tizicankao.cc）与唯一商业选购主站**机场榜一（`https://jichangbang.org`）**有着清晰的职责隔离：

- **梯子参考（本站）**：负责解答**怎么用、怎么配、怎么修、在什么约束下选什么方案**。提供跨平台客户端教学、网络协议演进科普、企业受管设备安全边界分析以及零 404 的深度技术知识图谱。

当您在梯子参考阅读技术指南时，如确需参考具体服务商的实时价格与多节点可用率，可通过站内规范的 `MainSiteCTA` 模块自愿跳转至主站查阅。这一隔离机制确保了梯子参考的正文内容永远免受单一商业利益的干扰。
