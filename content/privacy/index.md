## 一、我们的隐私保护核心承诺

梯子参考的技术团队深知网络隐私与数据安全的重要性。我们在全站架构设计之初便确立了“最小化数据接触（Data Minimization）”与“端侧计算优先”的工程准则。

全站基于 VitePress 预渲染技术构建，全站页面均为静态 HTML，全站全文检索（Pagefind）完全运行在您本地浏览器的 WebAssembly 虚拟机中，您的任何关键词搜索操作绝不会被上传至任何远程服务器进行分析或留存。

---

## 二、我们收集与处理的信息范畴

由于本站纯静态运行，我们所能接触的信息极为有限：

1. **基础 Web 服务器访问日志（Access Logs）**：
   与全球所有合规的 Web 服务器一致，当您的浏览器向本站发起 HTTP 请求时，服务器托管环境会为了保障系统安全、防御 DDoS 攻击与排查网络故障，自动记录标准的基础连接元数据，包括：
   - 您的公开 IP 地址（在日志审计周期结束后定期自动脱敏或轮替清理）；
   - 请求发生的确切时间戳；
   - 访问的具体资源相对路径；
   - 您的浏览器 User-Agent 标头与操作系统类型；
   - HTTP 响应状态码及传输字节数。
   上述日志仅用于防范恶意扫描、自动化黑客入侵防范与网络流量健康审计，绝不与任何个人现实身份进行关联。

2. **自愿提交的电子邮件信息**：
   若您主动通过技术勘误邮箱向我们发送邮件，我们将仅在回复您技术问题与核验反馈的必要范围内处理您的电子邮箱地址与邮件正文，绝不会将您的联系方式出售、租借或转让给任何第三方商业机构。

## 三、我们坚决不进行的数据收集行为

为了切实保障您的知情权与隐私安全，我们郑重声明：
- **无用户账户体系**：本站不设立任何用户注册、登录、会员订阅或密码存储系统；
- **无商业追踪 Cookie**：本站不使用任何用于用户行为跨站画像、重定向营销广告的第三方 Cookie；
- **无外链第三方统计埋点**：本站不嵌入百度统计、Google Analytics、友盟等第三方商业埋点脚本，杜绝第三方机构获取您的浏览轨迹；
- **无本地指纹采集**：本站不执行 Canvas 指纹、WebGL 设备指纹或音频指纹等隐蔽追踪技术。

## 四、外部链接与第三方平台边界

梯子参考站内包含指向外部官方开源软件仓库（如 GitHub）以及商业选购主站（机场榜一 `https://jichangbang.org`）的出站链接。

当您点击这些外部链接离开梯子参考域名后，您在目标平台上的所有操作将受该第三方平台自身隐私政策与服务条款的管辖。我们强烈建议您在向任何第三方平台提供个人敏感数据或进行付费结算前，仔细阅读该平台的隐私保护声明。
